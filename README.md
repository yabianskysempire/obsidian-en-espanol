# Obsidian en español: recursos y guías

Una lista de recursos para usar [Obsidian](https://obsidian.md/es/) en español: la ayuda y la traducción oficiales, plantillas gratis y guías prácticas paso a paso, con la interfaz en español.

## Recursos oficiales

- [Descargar Obsidian](https://obsidian.md/download) (gratis para Windows, Mac, Linux, iPhone y Android).
- [Ayuda oficial de Obsidian en español](https://help.obsidian.md/es).
- [Fuentes de la ayuda oficial en español](https://github.com/obsidianmd/obsidian-help/tree/master/es) (GitHub).
- [Traducciones oficiales de la app](https://github.com/obsidianmd/obsidian-translations): sirven para ver cómo se llama cada menú en español.
- [Foro oficial de Obsidian](https://forum.obsidian.md/) (en inglés).

## Plantillas gratis

- [Plantilla gratis de revisión semanal y nota diaria](https://github.com/yabianskysempire/plantilla-obsidian-revision-semanal) (bóveda lista para abrir; también se descarga desde [su página](https://yabianskysempire.github.io/fundador/plantilla-revision-semanal-gratis.html)).
